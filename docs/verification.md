# Состояние проверки

- Пройдены 5 тестов конфигурации: обязательные файлы, параметры NVMe/NVRAM, ограничения RAM, пара SEP и координаты указателя.
- JavaScript проверен на синтаксис. Статическая сборка интерфейса создаётся.
- Хост с паролем проверен отдельно: анонимный запрос получает HTTP 401, авторизованный запрос — HTTP 200. Это подтверждает работу интерфейса и авторизации, но не эмулятора.
- Нативная WASM-сборка не завершена: последний выполненный запуск остановился при компиляции GLib gconvert.c из-за несовместимых типов указателей gsize/size_t. Исправление включено в build/dependencies.sh, но повторная сборка после него не подтверждена.
- В web/runtime нет готового inferno.mjs и qemu-system-aarch64.wasm.
- Код подкачки OPFS/IndexedDB и его подключение к QEMU написаны, но не проверены в собранном эмуляторе. Тест tests/storage-browser.mjs включён; подтверждённого результата браузерной проверки нет.
- Реальная загрузка iOS не проверена: загрузочные файлы и образ ОС не предоставлены.
- Публикация на GitHub Pages не выполнена; совместимость с Pages ещё не подтверждена браузерным тестом.
- GIF реального запуска не создан.

Проект содержит исходники экспериментальной незавершённой реализации, а не готовый проверенный эмулятор.
